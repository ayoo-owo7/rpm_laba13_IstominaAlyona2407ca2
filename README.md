# Лабораторная работа №13
Тема работы:  Взаимодействие с базами данных в .NET. CRUD операции.

Цель работы:  изучить внутреннее устройство класса DbContext в Entity Framework Core, механизмы отслеживания изменений сущностей. Реализовать полный цикл CRUD-операций (Create, Read, Update, Delete) в приложении «Телефонная книга», работая с базой данных напрямую через контекст.


CRUD — это аббревиатура, которая обозначает четыре базовые операции для работы с данными в программировании:
  - Create — создание (добавление новых записей в систему). Например, регистрация пользователя, добавление товара в интернет-магазин, публикация поста. 
  - Read — чтение (получение и отображение данных). Например, просмотр списка заказов, чтение статьи, просмотр товаров. 
  - Update — обновление (изменение существующих данных). Например, редактирование профиля, изменение статуса заказа. 
  - Delete — удаление (устранение ненужных данных). Например, удаление аккаунта, комментария или товара из корзины. 
CRUD — это основа работы практически любой системы, где требуется управление данными: сайтов, мобильных приложений, банковских сервисов, CRM, интернет-магазинов, личных кабинетов и других сервисов. 
Некоторые особенности CRUD:
  - Реализация в базах данных. В SQL этим операциям соответствуют операторы: INSERT (создание), SELECT (чтение), UPDATE (обновление), DELETE (удаление). 
  - Реализация в веб-приложениях и API. Часто используется через HTTP-методы: POST для создания, GET для чтения, PUT или PATCH для обновления, DELETE для удаления. 
  - Гибкость и масштабируемость. Модель CRUD легко адаптируется под рост проекта. 
  - Контроль доступа. С помощью CRUD можно настроить, кто имеет право создавать, читать, изменять или удалять данные.
